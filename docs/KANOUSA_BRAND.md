# かのうさぎ ブランド仕様

この文書は、pokecloudbuilder公式サイトにおける公式案内役「かのうさぎ」の取り扱い基準です。サイトのデザインやかのうさを変更する前に、必ずこの文書と正本JSONを確認します。

## 1. 正本

- 正本データ：`/Users/kidayuichi/Documents/repos/KanoUsaRoulett/design/kanousa-character.json`
- サイト用正本SVG：`assets/kanousagi.svg`
- サイト用正本SVGの`metadata`に記録された正本JSONのSHA-256は、`aeea80328632ab4001c6789005eaeb0311f16f6b50255692221afd4629f40ecf`です。正本SVGを変更する場合も、この由来情報を維持します。

## 2. 基本形状

- viewBox：`0 0 624 284`
- 縦横比：`624:284`
- CSSで幅を変更する場合も`height: auto`を維持します。
- `object-fit: contain`を使用します。
- 引き伸ばし、押しつぶし、耳・顔・輪郭の切り取りを禁止します。

## 3. 基本カラー

| 用途 | カラー |
| --- | --- |
| 毛 | `#ffdce5` |
| 輪郭 | `#f58ca5` |
| 文字・口 | `#53363d` |

薄いブランドカラーを本文文字として使う場合は、可読性・コントラストを確認します。本文は原則として濃いインク色を使用します。

## 4. 変更禁止事項

- 顔、目、口、耳、輪郭の比率を勝手に変更しません。
- 正本SVGをAIで描き直しません。
- 写実化、3D化、別キャラクター化をしません。
- 新しい表情、衣装、ポーズを無断で追加しません。
- 色相を変更しません。
- 回転、反転、強い影、グラデーションで基本形を損ないません。
- ロゴや文字を顔の上に重ねません。

## 5. 新規バリエーション

新しい表情、ポーズ、衣装、アイコン版が必要な場合は、正本を直接変更せず別ファイルとして提案します。ユーザーの承認を得てから作成します。

## 6. デザイントークン

サイト共通の色、角丸、余白、影、文字サイズ、最大コンテンツ幅は`assets/site.css`のCSSカスタムプロパティで定義します。同じ値をページごとに手入力しません。
